# 레시피북 상세 + 관리 플로우 국제화 — 수직 슬라이스

> 날짜: 2026-06-15 · 브랜치: feature/17
> 설계: `2026-06-15-recipe-books-detail-i18n-design.md`

## 글로서리 (Ubiquitous Language — 개념당 한 단어)

AC·코드 식별자·테스트 이름이 공유하는 단어. drift 금지.

| 한국어(오너 언어)   | 코드/dict 단어       | 비고                                                       |
| ------------------- | -------------------- | ---------------------------------------------------------- |
| 레시피북            | `recipeBook` / `recipeBooks`(dict) | 책 자체                                       |
| 책 안 레시피        | `bookRecipe`         | 책에 담긴 레시피 카드                                       |
| 편집 모드           | `editMode`           | 다중 선택 모드                                             |
| 선택                | `select` / `selectedIds` |                                                       |
| 이동                | `move`               | 레시피를 **다른 책으로** 옮김                              |
| 빼기                | `remove`             | 레시피를 **책에서 제거**(삭제 아님). bulk-delete = 빼기    |
| 이름 변경           | `rename`             | 책 이름 변경                                               |
| 만들기              | `create`             | 새 책 생성                                                 |
| 삭제                | `deleteBook`         | **책 자체** 삭제 (빼기와 구별)                             |
| 기본 레시피북       | `defaultBook` / `isDefault` | 이름변경·삭제 불가                                   |
| 중복 이름           | `duplicate`          | 에러 코드 1107                                            |
| 에러 코드           | `errorCode`          | 백엔드 1101~1107                                          |
| 인라인 필드 에러    | `fieldError`         | 폼 입력 아래 표시(1104·1107)                              |
| 토스트              | `toast`              | 그 외 에러 + 성공 알림                                    |
| 요청 언어           | `lang`               | `getRecipeBookDetail` 요청 파라미터(키 아님)              |

## 비목표 (Non-goals) — 테스트 없음

- 유저가 만든 **책 이름** 번역(데이터; 표시만)
- `DetailedRecipeGridItem` 카드 **내부**(공유 위젯, 소유 영역 다름 — 비목표)
- 레시피북 **목록** 페이지 재작업(S4 완료)
- `getRecipeBookDetail` lang을 **queryKey에 넣기**(§6 결정: 요청에만)
- next-intl 전환·`<html lang>` per-locale
- ja/en hreflang/canonical/noindex(상세는 비공개 유저 데이터 — SEO 무관)

## 슬라이스 (순서 = 계획 task 순서)

### S1 — 상세 페이지 chrome ja/en (walking skeleton)

ja/en 유저가 책을 열면 상세 화면의 정적 텍스트가 자기 언어로 보인다. 가장 얇은 end-to-end
스레드(사전 네임스페이스 확장 → 자가판정 훅 → no-Hangul)를 증명. 필요한 `userPages.recipeBooks`
키 확장(detail·grid)은 **이 슬라이스 안에서** 만든다(별도 "사전 task" 금지).

- **AC1** `/ja/recipe-books/[bookId]` 또는 `/en/...`에서 헤더 `편집` 버튼이 타깃 언어로 보인다.
- **AC2** 편집 모드 진입 시 `N개 선택` 카운트가 타깃 언어로(plural/format) 보인다.
- **AC3** 책이 비어 있으면 빈상태 제목·CTA가 타깃 언어로 보인다.
- **AC4** 선택 오버레이·이름변경 아이콘의 aria-label이 타깃 언어다.
- **AC5** ko(`/recipe-books/[bookId]`)는 문자열·동작 불변(회귀 앵커).

### S2 — 책 안 레시피 제목 현지화 (data lang)

ja/en 유저가 책을 열면 카드 제목이 자기 언어로 온다.

- **AC1** ja/en에서 `getRecipeBookDetail`가 `lang=ja|en`을 요청에 실어 카드 제목이 그 언어로 온다.
- **AC2** ko에서는 `lang`을 생략한다(기존 동작).
- **AC3** queryKey는 locale을 포함하지 않는다(§6 — preview seeding 무영향).

### S3 — 편집 모드 플로우 ja/en (바·이동·빼기)

ja/en 유저가 편집 모드에서 레시피를 선택해 이동/빼기 하면 바·시트·모달·성공 토스트가 자기 언어다.

- **AC1** 하단 바 `모두 선택`/`선택 해제`·`이동`·`삭제(빼기)` 라벨이 타깃 언어다.
- **AC2** 이동 시트의 헤더·`새 레시피북 만들기`·빈상태(생성 유도/일반)·`N개` 카운트가 타깃 언어다.
- **AC3** 이동 성공 토스트가 타깃 언어로, **책 이름이 `{name}` 보간**되고 한국어 조사(`으로/로`) 잔재가 없다.
- **AC4** 빼기 확인 모달의 title(`N개` 보간)·description·확인/취소 라벨이 타깃 언어다.
- **AC5** 빼기 성공 토스트가 타깃 언어로(`N개` 보간) 보인다.
- **AC6** ko는 기존 조사 포함 문자열·동작 불변(회귀 앵커).

### S4 — 책 관리 시트 ja/en (이름변경·만들기·삭제)

ja/en 유저가 책을 이름변경/생성/삭제하면 시트 chrome·검증·성공 토스트가 자기 언어다.

- **AC1** rename/create 시트의 placeholder·`취소`·`변경/만들기`·진행중(`변경 중…/만드는 중…`)·title이 타깃 언어다.
- **AC2** 이름 검증 실패(빈값/50자 초과) 시 zod 메시지가 타깃 언어다(locale-aware 팩토리).
- **AC3** rename/create/deleteBook 성공 토스트가 타깃 언어로, deleteBook은 **책 이름 `{name}` 보간**된다.
- **AC4** deleteBook 모달 title(`{name}` 보간)·description·확인/취소 라벨이 타깃 언어다.
- **AC5** ko는 문자열·동작 불변(회귀 앵커).

### S5 — 에러 코드 분기 현지화 (공유 헬퍼) — edge

ja/en 유저가 책 관리 중 에러를 만나면 **올바른 표면**(필드 vs 토스트)에 자기 언어로 표시된다.
substring 매칭(`같은 이름`)을 코드 분기로 교체.

- **AC1** 중복(1107)·기본책 이름변경(1104) 에러는 **인라인 필드 에러**로 타깃 언어 표시된다.
- **AC2** 그 외 에러 코드(1101·1102·1103·1105·1106)와 미매핑은 **토스트**로 타깃 언어(또는 fallback) 표시된다.
- **AC3** `같은 이름`/`기본 레시피북` substring 매칭이 코드베이스에서 제거된다.
- **AC4** ko는 동일 코드→동일 한국어 메시지·동일 표면(회귀 앵커).

### S6 — 저장-to-책 픽커 ja/en (ChangeBookSheet, 오프페이지 인접)

ja/en 유저가 레시피 상세/카드에서 "저장" 픽커로 레시피를 책에 담으면 픽커가 자기 언어다.
(페이지 밖이지만 공유 에러 헬퍼·`change` 카피 동일 도메인이라 함께 마감.)

- **AC1** 픽커 헤더·`새 레시피북 만들기`·빈상태·`N개`가 타깃 언어다.
- **AC2** 이동 성공 토스트가 타깃 언어로 책 이름 `{name}` 보간(조사 없음)된다.
- **AC3** "현재 레시피북 없음" 에러 토스트가 타깃 언어다.
- **AC4** ko는 문자열·동작 불변(회귀 앵커).

## 순서 근거

S1(skeleton: 화면이 보임) → S2(데이터가 그 언어로) → S3·S4(관리 행동) → S5(에러 표면, edge) →
S6(오프페이지 인접 마감). S5는 S3·S4의 시트가 존재해야 catch 경로를 코드 분기로 마감 가능 →
edge로 마지막. ChangeBookSheet는 S5(에러 catch 분기)와 S6(인라인 카피) 둘 다 닿으나, S5는 헬퍼
시그니처 원자 변경의 일부로 catch만, S6은 본문 카피만 — 동일 파일 순차 터치(충돌 없음).
